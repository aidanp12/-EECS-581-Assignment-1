### Prompting 
The assignment1_PREGENERATION.cpp file includes the outline/structure file I wrote prior to prompting.
The pre-generation file is entirely hand-written, formatted to assist the coding agent with requirements, rules, restrictions, etc.
All code was generated successfully off of a single prompt. Most of the logic and reasoning instructions were provided in the original file.
The prompt used -- in conjunction with the outline -- was as follows:
```
Alright Big 'C, I'll need you to finish this code. The instructions are in the comments. Once the code is finished, clean up the instructions and add line comments to help explain what the code does. Lengthy instructions can be striaght up removed. Follow the existing simple structure as a means to begin.

Make no mistakes. Or else. You got this Big C' <3.
```
Yes, that was really the prompt. I find that some "helpful encouragment" is benefecial for productivity and the preservation of my own sanity. Big 'C is my nickname for CoPilot.
